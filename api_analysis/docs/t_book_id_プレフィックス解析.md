# ReelShort t_book_id プレフィックス解析レポート

**作成日**: 2025-12-25  
**分析対象**: 2,817作品（日本語版 + 英語版）

---

## 📊 概要

ReelShortの各作品には `t_book_id` という内部識別子が付与されています。この識別子を分析した結果、明確な構造規則を発見しました。

---

## 🔍 t_book_id の構造

```
t_book_id: XXXYYYY P SSSSSS NNNNNNNNN
           │  │    │ │      └── 作品固有番号
           │  │    │ └── サブシリーズコード (6桁)
           │  │    └── プレミアムフラグ (1桁: 0=通常, 1=プレミアム)
           │  └── コンテンツタイプ (4桁)
           └── 地域コード (3桁)
```

### 例

```
140000000140000001
│││    │ │     └── 作品番号: 001
│││    │ └── サブシリーズ: 140000 (日本オリジナル)
│││    └── プレミアム: 0 (通常)
│└└── コンテンツタイプ: 0000 (オリジナル)
└── 地域: 140 (日本)

結果: 日本人キャストによる日本オリジナル作品
```

## 🔬 分析手法

1. 日本語版API (`language=ja`) と英語版API (`language=en`) から全作品を取得
2. `t_book_id` フィールドを抽出し、先頭3桁・15桁でグループ化
3. 各グループの作品例を確認し、パターンを推定
4. ユーザー提供の「日本人キャスト作品リスト」と照合して精度を検証
