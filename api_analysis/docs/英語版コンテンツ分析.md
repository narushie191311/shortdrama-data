## 🔍 プレフィックス構造（英語版）

```
t_book_id: XXX YYY P SSSSSS NNNNN
           │   │   │ │      └── 作品固有番号
           │   │   │ └── サブシリーズ
           │   │   └── プレミアムフラグ (0=通常, 1=プレミアム)
           │   └── コンテンツタイプ
           └── 地域/シリーズコード
```

## 💡 主な発見

### 1. 市場規模の差
英語版は日本語版の**約17倍**の総再生数を持つ巨大市場。

### 2. ヒット作の差
英語版のTOP1（5億再生）は日本語版TOP1の**23倍**。スケールが全く異なる。

### 3. コンテンツ戦略
- **オリジナル制作重視**: 全体の77%がオリジナル
- **プレミアム戦略**: 少数精鋭で高再生数を狙う
- **吹き替え展開**: 中国作品を英語市場に展開

### 4. ReelTalkの役割
俳優のファンエンゲージメントを高めるためのトーク番組コンテンツが存在。
